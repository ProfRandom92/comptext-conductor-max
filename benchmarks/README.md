# Reproducible context benchmark

This synthetic benchmark creates a deterministic repository with many source files, large Conductor `spec.md`/`plan.md`, a large working-tree diff, generated/lock content, a binary change, and a 6,500-line test log. It compares a naive full-context payload with SAFE, BALANCED, and MAX broker workflows.

Metrics are measured from generated bytes and the project's explicit `estimated_tokens` fallback. They are not claims about all repositories, all models, or production latency. Required facts are embedded in the fixture manifest and every run reports missing facts. The quality gate requires at least one of BALANCED/MAX to reduce delivered estimated tokens by 50% or more with zero missing required facts.

Run: `python benchmarks/run_benchmark.py --output benchmarks/results/latest.json`.
